# 深职大双高中期自评报告说明

本说明仅对应所选szpt-midterm模板，配合本轮共同写作规则及固定模板工具流程使用。原文档的40张表、完整章节、图片、分节和混合样式为编写基准，表格结构不得简化。

## 对象与期间

- 学校和两个专业群分别定位；专业群名称取国双高项目名称，不照抄示例，不把两个专业群直接相加充当学校整体。
- 区分报告年度、截止日、建设周期与预算期间。已整理年度取数规则不等于建设期累计口径；不能用当前进度或后续年度补录冒充历史实绩。
- 来源角色hpm对应本模板获准数据源，业务指标名称/ID如下；先通过data工具读取完整定义、参数和关联口径，不从模板另造SQL。

## 章节与数据来源

| 原文用途 | 指标名称及ID | 撰写口径 |
| --- | --- | --- |
| 学校、专业群和负责人 | 国双高项目名称 project_catalog；项目负责人名单 project_leaders；项目年度阶段 stage_catalog | 先确定授权对象、同名歧义及年度阶段，再替换名称和介绍 |
| 总体任务进展 | 年度任务层级数量 task_level_counts；任务进度与阈值统计 task_progress_summary | 各层级分别统计；完成阈值按定义，不混合层级或擅称达标 |
| 建设章节及落实立德树人根本任务 | 项目年度任务层级目录 task_tree；一级任务下属进度与反馈覆盖 first_task_progress_feedback | 按实际周期一级任务及父子关系定位；用户已确认编码1当前对应落实立德树人根本任务，不能沿旧模板名称推断其他周期 |
| 建设举措、学生综合素质、经验做法 | 报告期已审核任务反馈材料 task_feedback_candidates；任务负责人和参与人 task_members | 逐条读反馈正文及可核实附件后组织文字；简短数字/测试文字不足以支撑成果结论，反馈条数不是成果数量 |
| 产出、效益、满意度及任务绩效 | 年度三级任务关联绩效目标与完成值 task_performance_links；项目绩效一二级分类目录 project_performance_categories；绩效分类树和当前值 performance_tree | 绩效分类树与建设任务树不同；通过关系取值，按绩效ID去重，保留定性目标和原单位 |
| 年度与当前绩效概况 | 指定年度阶段绩效统计 performance_stage_summary；当前绩效指标统计 performance_current_summary；绩效模块口径诊断 performance_module_status | 先检查模块/阶段模式；当前值不能替代指定年度数据，模式未启用不得换口径规避 |
| 历史绩效材料核查 | 已审核绩效反馈版本候选 performance_feedback_candidates | 候选版本不自动等于历史快照；缺有效版本口径时不能给出历史完成结论 |
| 资金投入、到位与执行 | 项目年度预算到位与执行 fund_totals；资金七类来源与四类金额 fund_source_amounts；项目全建设期预算 project_cycle_budget | 年度与全周期分开，按来源字典和原单位写值；无阶段一级资金行为全周期预算，不视为年度值 |
| 部门任务与责任 | 牵头部门任务统计与排名 task_department_metrics；任务主部门名称候选 task_department_candidates | 部门别名及项目范围核实后再排名，参与关系不重复累计 |

## 特有规则及未确认范围

- 原绩效表中的评价维度不能直接认作新周期任务映射；任务按一级→二级→三级父键定位，绩效目标/完成值按关系表关联。跨章节引用同一成果不能重复汇总。
- 查无记录可以确认查询及表结构，不代表业务没有开展；已审核反馈也须核验内容质量。正文依照共同证据规则完成，不用无意义数字写成结论。
- 评分权重、等级、单项完成率、终期累计完成度及标志性成果计数仍须有明确规则和可用证据；未定义指标不执行，不能将模板样例得分当默认值。
- 图示无新证据时保留其结构，在说明位置标黄适用性待核实；不把旧成果、旧组织关系当作当前事实。
- 人工逐页来源整理已处理到学生综合素质及产出收尾；其余页面先理解原文、再检索指标和取证，不能视为已完成逐页确认。该核对记录保留在仓库，不作为整份运行提示词加载。
