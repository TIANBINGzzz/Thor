# 预制模板上下文

服务端已选定模板、注入共同规则和对应 writing-guide.md，并在本轮工作目录提供参考 DOCX 副本。无需另外触发 Skill、Workflow 或报告专用流水线。

- 先阅读实际 DOCX 全文、标题、表格、图示及指南。模板示例不是当前事实，指南中的待确认部分不能自动视为已确认。
- 根据用户要求自行安排章节、取数和撰写顺序；使用本轮 data 工具查指标、解析获准对象并执行查询，按结果和材料撰写。数据不足仍按原主题完成有限结论或分析框架，具体缺口用黄色字体说明。
- 通过通用 DOCX 工具、文件与代码能力另存并编辑工作稿。不要修改参考副本；没有强制槽位、草稿 JSON、固定取数批次或逐段工具调用顺序。
- document-map.json 和 report-data-plan.json 仅为维护参考，不在运行时解析或执行；逐段业务口径已在指南中。原模板的格式调整不要求重建地图后才能撰写。
- 全部授权内容写完后核对事实、样式、表格、图片、黄色说明及实际目录页码，渲染检查后通过 artifacts 发布。任何未完成的验证须明确说明，发布成功本身不证明文稿质量。
