# 歧义解析

问数输入只提供自然语言问题，不允许模型自行创建未绑定的 `:tenantId`、`:projectId`、`:stageId` 或 `:mainOrgId` 实际值。

1. 先识别问题中的项目、专业群、年度、部门、人员、层级和指标词。
2. 对名称在当前租户和国双高范围内查询候选，使用名称、年度、类别、层级等业务字段展示候选；不得展示 ID。
3. 0 条候选：保留原条件并说明没有找到，不能删除条件或扩大到其他租户/表。
4. 多条候选：暂停统计，请用户确认；绝不能用 `LIMIT 1`、最早记录或任意相似名称静默选择。
5. 仅给年度且问题是全校范围时，直接关联阶段表按 `name_` 过滤，不将年度绑定到一个阶段。
6. “完成率”“完成进度”“预算”“执行”“当前”等词存在多种业务含义时，按语义层默认口径回答并同时注明；无法判定则先澄清。

内部 SQL 可以使用解析得到的 ID 做关联和过滤，但最终列、自然语言、图表、导出文件和日志不能出现任何内部 ID。
