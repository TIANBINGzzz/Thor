# 问数输出契约

回答按以下顺序组织，默认不展示 SQL：

1. **结论**：直接回答数量、金额、比例或排名。
2. **口径**：说明国双高范围、实体粒度、层级、完成定义、资金层级、单位和时间范围，但是不能提到具体的sql和数据库筛选条件。
3. **证据**：说明使用了哪些允许表、查询是否执行成功、必要时给出记录覆盖率。
4. **限制**：说明空值、未填报、歧义、关联缺失、低覆盖率或数据质量风险。

结果字段只保留用户所需业务字段。不得展示实际 ID、连接信息、凭据、用户编号、联系方式、附件地址或审计字段。人员姓名只有在用户明确要求人员明细且业务允许时才返回；普通统计只返回人数。

金额保留两位小数并标明“万元”；百分比保留两位小数并说明分子/分母。分母为零、结果为空或关联覆盖率低于 95% 时，必须明确说无法形成全量可靠结论。
