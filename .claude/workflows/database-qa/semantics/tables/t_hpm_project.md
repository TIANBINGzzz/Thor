# t_hpm_project

粒度：一行一个项目。主键：`id_`。逻辑删除：`delete_flag_ = '0'`。

| 字段 | 语义 |
|---|---|
| `tenant_id_` | 租户隔离，所有查询必带 |
| `id_` | 项目主键，仅内部关联，不可输出 |
| `name_` | 项目名称 |
| `high_flag_` | `1` 国双高，`0/2` 为其他类别 |
| `progress_` | 项目进度 |
| `state_` | `0` 未启动、`1` 已启动、`2` 终止、`3` 归档 |
| `start_time_` / `end_time_` | 项目起止时间 |
| `level_name_` | 项目级别名称，可能是多值文本 |
| `province_high_flag_` | 省双高标记 |

项目是所有任务、绩效、资金等统计的范围锚点。国双高项目过滤为 `high_flag_ = '1'`，关联子表时同时校验租户和 `project_id_`。
