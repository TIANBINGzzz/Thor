# t_hpm_project_stage

粒度：一个项目下的一个阶段/年度记录。主键：`id_`。有效记录：`delete_flag_ = '0'`。

| 字段 | 语义 |
|---|---|
| `tenant_id_` | 租户隔离 |
| `id_` | 阶段主键，仅内部使用 |
| `project_id_` | 所属项目 |
| `name_` | 阶段名称；国双高通常是年份，如 `2026` |
| `start_time_` / `end_time_` | 阶段起止时间 |
| `current_flag_` | `1` 当前阶段，`0` 非当前 |
| `delete_flag_` | `0` 有效，`1` 删除 |

年度必须按阶段名称跨项目过滤；同名年度可能对应多个项目，不能静默绑定一个阶段。
