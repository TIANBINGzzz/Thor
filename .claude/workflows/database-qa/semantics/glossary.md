# HPM 术语与指标语义层

本语义层提炼自 DBProcessing 的 `国双高AI问数LLM精简上下文.md`、`SQL生成LLM运行时上下文.md` 和硬约束规范。它描述业务口径，不包含租户实际值、凭据、内部 ID 或人工校验快照。

## 数据源

- 数据库：MySQL `test_hpm_dev`。
- 允许表：项目、阶段、模块、项目成员、任务、任务反馈、任务成员、任务负责部门、绩效、绩效反馈、绩效负责部门、资金，共 12 张，完整字段见 `semantics/tables/`。
- 当前 workflow 只读；表均为逻辑关联，不能依赖物理外键。
- `database-qa` 的默认业务范围就是国双高口径；项目/资金/绩效以有效国双高项目为范围，纯任务统计以有效国双高任务为范围。问题省略“国双高”时仍必须应用该范围，不能统计全库或无阶段任务。

## 术语映射

| 用户术语 | 默认口径 |
|---|---|
| 国双高项目 | `t_hpm_project.high_flag_ = '1'` 且有效 |
| 国双高任务 | `t_hpm_project_task.high_flag_ = '1'` 且有效 |
| 年度 | 国双高项目阶段 `t_hpm_project_stage.name_`，例如 `2025` |
| 本年度 | 用户提供或系统明确的年份；不能按当前日期猜测 |
| 真实年度任务 | `task.stage_id_ IS NOT NULL` |
| 三级任务 | `task.level_ = 3`，默认末端填报层级 |
| 已完成任务 | `progress_ >= 100`，包含提前/超额完成，不看 `state_` |
| 真实绩效指标 | `performance.level_ >= 3`，并遵守阶段绩效开关 |
| 绩效达标 | `progress_ >= 100` |
| 牵头部门 | `task_org.main_org_id_ / main_org_name_` |
| 项目负责人 | `project_member.type_ = '0'` |
| 专业群 | 已确认与国双高项目一一对应 |
| 支撑材料 | 审核通过任务反馈且附件非 NULL、非空串、非 `[]` |

## 口径区别

- 完成进度：平均 `progress_`，空进度按业务语义通常以 0 参与平均。
- 完成率：`COUNT(progress_ >= 100) / COUNT(有效实体) * 100`，分母为 0 时不可计算。
- 资金金额：字段金额单位为万元；资金树默认一级节点，避免父子重复。
- “无数据”“未填报”和“数值为 0”必须分别说明，不能互相替换。
