# 007 - 文件上传改为待上传模式

日期: 2026-08-17  
决策状态: 已采纳
实现状态: 已实现
替代: 无
被替代: 无

## 背景

原文件上传点击即上传，用户无法预览或取消，且不符合主流产品（ChatGPT、Claude）的交互习惯。

## 决策

参考 ChatGPT 模式：
1. 点击 + 或粘贴文件后，显示在输入框上方作为"待上传"状态
2. 用户可删除待上传文件
3. 发送消息时统一上传所有待处理文件
4. 上传后清空待上传列表

## 后果

### 好处
- 用户可预览和控制要上传的文件
- 符合主流产品交互习惯
- 支持批量上传

### 代价
- 需维护 pendingFiles state
- 发送时需异步上传文件

### 风险
- 大文件上传可能阻塞消息发送
