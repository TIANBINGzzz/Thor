# ADR-003: 使用容器隔离工作目录

日期: 2026-08-17
状态: 提议

## 背景

当前入口启用 `bypassPermissions` 和完整 Claude Code 工具集，模型可以通过 `Bash` 绕过所有文件工具限制。给单个工具加路径校验无法构成真正的安全边界。

## 决策

把 Agent 跑在容器里，挂载策略为：
- `/workspace/session/<id>` → 可读写
- `/workspace/project` → 只读
- 其余 → 不挂载

## 后果

### 好处
- 边界由内核保证，不依赖命令解析
- 不需要完全禁用 `Bash`，保留 `node` 执行和 `npm view` 等数据获取能力
- 架构可直接用于生产，不是过渡方案

### 代价
- 需要确定容器运行时与镜像
- 本机开发流程需要适配（当前 `npm run ui` 是裸进程）
- 增加部署复杂度

### 风险
- 容器逃逸风险（但远低于无隔离）
- Windows 容器支持相对 Linux 更复杂
