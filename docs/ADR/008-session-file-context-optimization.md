# 008 - 会话文件上下文优化

日期: 2026-08-17  
状态: 已完成

## 背景

模型在读取上传文件时找不到路径，导致反复思考和推理，无法完成任务。

## 问题原因

`sessionPromptContext` 给模型的文件信息格式不清晰：
- 只有简单的一行描述
- 路径字段可能为空或格式不明确
- 缺少明确指引模型如何读取文件

## 决策

优化文件上下文格式：
1. 每个文件多行显示：文件名、路径、大小、类型
2. 确保路径字段始终是完整的绝对路径
3. 明确指引模型使用 Read 工具读取路径
4. 避免模型猜测路径或反复推理

## 后果

### 好处
- 模型可直接使用完整路径读取文件
- 减少无效推理和重复思考
- 提升文件处理任务成功率

### 代价
- 上下文稍长（但更清晰）

### 风险
- 无
