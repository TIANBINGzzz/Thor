# 009 - 修复文件上传注册和 Chip 显示

日期: 2026-08-17  
决策状态: 已采纳
实现状态: 已实现
替代: 无
被替代: 无

## 背景

1. Skill chip 显示在输入框内部，应该在上方独立显示
2. 文件上传后物理文件存在，但 session.files 数组为空，导致模型找不到文件

## 问题原因

1. **Chip 样式问题**：缺少明确的边界和背景，视觉上融入输入框
2. **文件注册问题**：上传时使用的 session 对象可能是过期的缓存，导致 files 数组未正确更新到持久化存储

## 决策

1. **Chip 样式改进**：
   - 添加底部边框分隔
   - 添加背景色区分
   - 去除 min-height，让空状态不占空间

2. **文件上传修复**：
   - 上传前重新加载 session（`loadSession(id)`）
   - 使用最新状态更新 files 数组
   - 持久化后同步更新内存缓存

## 后果

### 好处
- Chip 视觉上与输入框明确分离
- 文件上传后正确注册到 session
- 模型可以看到完整的文件路径

### 代价
- 上传时额外一次 session 加载（性能影响可忽略）

### 风险
- 无
