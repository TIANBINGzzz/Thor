## 背景

- @ 引用选择后无视觉反馈
- 消息发送后输入框不清空
- 需要 @skill: 引用类型

## 决策

1. 添加 @skill: 引用支持，扫描 .claude/skills/ 目录
2. 引用显示为彩色 chip（⚡ skill 蓝色、📦 pkg 绿色）
3. 监听表单提交清空输入框
4. 添加粘贴上传功能

## 后果

### 好处
- 引用有清晰视觉标识，参考 Cursor 设计
- Skill 可被引用，保持工作区与项目 Skill 文件同步
- 输入框行为符合预期
- 文件上传体验更好

### 代价
- 新增 ReferenceChips.tsx 和 Portal.tsx 组件
- `python/local/references.py` 增加 skill 数据源

### 风险
- skill 数量过多时加载性能（30 秒缓存缓解）
