# ADR-002: 使用 MCP 动态挂载数据库

日期: 2026-08-17
状态: 已采纳

## 背景

Agent 需要访问数据库，但连接凭证不能写入项目配置文件或提交到 Git。

## 决策

使用 MCP（Model Context Protocol）在 `app/database.mjs` 中动态挂载数据库，而不是在 `.mcp.json` 中静态配置。

## 后果

### 好处
- 可以按租户在运行时注入不同的数据库连接
- 凭证只放在 `.env`，不提交到版本控制
- `.mcp.json` 保留给无需按租户变化的静态 MCP 服务

### 代价
- 多一层抽象，相比直接集成 ORM 更复杂
- MCP 服务需要额外进程

### 风险
- 当前使用 DBHub，其稳定性和功能完整性依赖上游维护
