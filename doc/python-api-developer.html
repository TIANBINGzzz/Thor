业务调用

01 获取能力列表

地址GET/internal/v1/capabilities

说明 获取可用能力及是否支持附件，供业务端展示能力列表。

输入 无需 JWT；无正文

输入示例 无参数，不发送正文
{}

输出 200：{"capabilities":[能力摘要]}。

字段类型与必填说明
capabilityRefstring创建 Run 时使用的能力标识。
name / descriptionstring显示名称和简要说明。
supportsAttachmentsboolean是否接受 input.attachmentRefs。
输出示例 200 JSON
{

    {

      "name": "校园大脑问数",
      "description": "查询本校指标、预置群体对比与自选学校组常模分析",
      "supportsAttachments": true
    },
    {
      "capabilityRef": "chart-generation",

接口联动 选取 capabilityRef → 02 发起任务。新增能力见 16。

02 发起任务

地址POST/internal/v1/runs

说明 提交用户消息并启动一次任务，返回任务状态和事件订阅地址。

输入 Run JWT，scope 为 run.execute，消费 jti；下表为 JSON 正文

字段类型与必填说明
protocolstring 必填固定 agent-run/v1。
runId / messageIdstring 必填分别标识一次执行和触发它的业务消息。
businessSessionIdstring 可选连续会话标识；与 JWT 中的同名字段保持一致。
capabilityRefstring 可选省略或 null 按 conversation 执行；JWT 仍绑定 conversation。空字符串无效。
domainNamestring 必填业务端从已认证学校上下文取得的文件路由域名；只传域名，不含协议、端口或路径。JWT 不绑定此字段。
inputobject 必填可传 {}；text、attachmentRefs、payload 至少一项非空。
input.textstring 可选自然语言需求；默认空串，最多 1,000,000 字符，不含 NUL。
input.attachmentRefsarray 可选最多 64 项；每项仅含 fileId 和 purpose。
fileId / purposestringfileId 必填，为已获授权的平台文件 ID；purpose 为 input（默认）或 reference。
payloadobject 可选默认 {}；JSON 序列化后最多 65,536 UTF-8 字节，嵌套最多 16 层。预制模板传 templateKey。
credentials.platformBearerstring 条件必填当前请求的业务 Token，最多 16,384 字符。能力或所选工具要求时必填；不是 Run JWT。

字段限制 ID 使用英文字母、数字、下划线或连字符，首字符为字母或数字，最长 256 字符。请求和 input 不接受未定义字段。

输入示例 JSON 正文
{
  "protocol": "agent-run/v1",
  "runId": "run_demo_01",
  "messageId": "msg_demo_01",
  "businessSessionId": "session_demo_01",
  "domainName": "school.example.com",
  "input": {"text": "请简要介绍文档校对方法。"}
}

输出 首次创建 202，幂等重试 200：{"run":Run状态,"eventsUrl":"/internal/v1/runs/{runId}/events"}。Run状态字段见 03。

输出示例 202 JSON
{
  "run": {"runId": "run_demo_01", "status": "queued", "lastSequence": 0},
  "eventsUrl": "/internal/v1/runs/run_demo_01/events"
}

边界说明 传输重试保留 runId 和非凭据正文，重新签发新 jti；不同内容或归属返回 409。重新执行使用新 runId。payload 不得携带凭据、身份或模型/工具/工作目录等执行配置；普通请求使用 {}。HTTP 接收成功不代表执行成功。

接口联动 01 选能力 → 本接口 → 04 SSE；03 补查状态，06 取消，09 查询生成文件。同身份同 businessSessionId 的 Run 串行续接历史，切换能力仍保持会话。

模板和附件 预制模板：document-writing + payload={"templateKey":"szpt-midterm"}。上传模板：在 attachmentRefs 中传已授权 fileId，并在 input.text 说明用途；payload 中的 fileId 不触发下载。附件应在再次需要时重新提交。

输出类型 图表通过 message.delta 返回 Mermaid 正文；图像及文档文件通过 artifact 事件交付。

03 查询任务状态

地址GET/internal/v1/runs/{runId}

说明 查询任务是否排队、执行中、成功、失败或已取消。

输入 Run JWT，scope 为 run.read 或 run.execute，不消费 jti；路径 runId；无正文

输入示例 路径及查询参数，不发送正文

GET /internal/v1/runs/run_demo_01

{"runId": "run_demo_01"}

输出 200：{"run":Run状态}。创建、查询、控制和取消共用此对象。

字段类型与必填说明
runIdstring执行标识。
statusstringqueued、running、succeeded、failed、cancelled。
lastSequenceinteger已持久化的最大事件序号；无事件时为 0。
errorstring 可选失败原因代码；无错误时省略。
输出示例 200 JSON
{"run": {"runId": "run_demo_01", "status": "running", "lastSequence": 1}}

边界说明 不返回回答全文、业务消息或引导回执。404 表示 Run 不存在；不能据此判断鉴权成功。

接口联动 回答及引导回执从 04 补放；续传使用已处理序号，不用 lastSequence 跳过未处理事件。

04 订阅任务事件

地址GET/internal/v1/runs/{runId}/events

说明 接收回答正文、执行进度和文件事件；断线后可补收已保存事件。

输入 Run JWT，scope 为 run.read 或 run.execute，不消费 jti；路径 runId；查询 afterSequence 为非负整数，默认 0。未传查询参数时可用 Last-Event-ID 请求头

输入示例 路径及查询参数，不发送正文

GET /internal/v1/runs/run_demo_01/events?afterSequence=0

{"runId": "run_demo_01", "afterSequence": 0}

输出 200 text/event-stream；每帧含 id、event、data，空行结束。data 是下述 JSON 对象。

字段类型与必填说明
protocolVersionstring固定 agent-events/v1。
runId / eventIdstring执行标识 / 事件标识。
sequence / occurredAtintegerRun 内递增序号 / Unix 毫秒时间。
type / payloadstring / object事件类型和对应数据，见下表。
payload.displayNamestring状态显示文字；空串只隐藏提示，仍须处理该事件。
事件类型关键 payload 字段调用方处理
run.startedstatus=running执行开始，可能仍在准备附件。
phasename；可能带 fileId、receivedBytes、totalBytes、fileCount显示阶段或文件准备进度。
message.deltatextDelta按 sequence 追加正文，同一事件只追加一次。
tool.started / tool.progress / tool.finishedtoolKey、scope、status；可带 toolCallId，结束带 isError按 Run、scope、toolCallId 关联调用，结束时更新状态。
steering.accepted / delivered / applied / rejected / unknownmessageId、status；可带 code关联补充要求，状态含义见 05。
artifact.pending / uploading / ready / failed / unknown文件对象字段，见 09按 artifactId 更新文件卡片；ready 后使用 fileId。
run.completed可带 inputTokens、outputTokens、turnsRun 成功结束；文件是否成功仍看各文件状态。
run.failedcode、message；可带用量Run 失败结束；message 为安全提示。
run.cancelleddisplayNameRun 已停止，保留已收到的内容和文件。
输出示例 200 SSE 中一条 data 解析后的 JSON
{
  "protocolVersion": "agent-events/v1",
  "runId": "run_demo_01",
  "type": "message.delta",
  "payload": {"textDelta": "先核对事实，再检查结构，最后统一格式。", "displayName": ""},
  "eventId": "evt_f8a46d724dc74437b68939f5b8f2be2a",
  "occurredAt": 1794467502363,
  "sequence": 3
}
SSE 原始帧示例
id: 3
event: message.delta
data: {"protocolVersion":"agent-events/v1","runId":"run_demo_01","type":"message.delta","payload":{"textDelta":"先核对事实，再检查结构，最后统一格式。","displayName":""},"eventId":"evt_f8a46d724dc74437b68939f5b8f2be2a","occurredAt":1794467502363,"sequence":3}

边界说明 仅补放 sequence 大于游标的事件；查询参数优先。心跳是注释帧，不占序号。断开 SSE 不取消 Run；终态后补放完即关闭。已提交文件上传收尾后才发送 Run 终态，但文件仍可能 failed 或 unknown。

接口联动 02 返回 eventsUrl；05 引导沿用原流；断线时用已处理序号重连，必要时配合 03 和 09 补查。

05 补充任务要求

地址POST/internal/v1/runs/{runId}/steer

说明 向正在执行的任务追加文字要求，继续使用原任务和回答流。

输入 Run JWT，scope 为 run.execute，不消费 jti；路径 runId；JSON 仅含 messageId 和 input.text

字段类型与必填说明
messageIdstring 必填本次补充要求的唯一标识，不能使用 Run 的原触发 messageId。
input.textstring 必填非空，最多 16,384 字符；不含 NUL；去除前导空白后不能以 / 或 ! 开头。
输入示例 JSON 正文

POST /internal/v1/runs/run_demo_01/steer

{"messageId": "msg_demo_02", "input": {"text": "补充要求：请按三个步骤说明。"}}

输出 首次接收 202，原请求重试 200：{"steering":{"runId":"…","messageId":"…","status":"accepted","code":null}}。

回执状态含义
accepted已持久接收。
delivered已写入 SDK Client。
appliedSDK 已用消息 UUID 确认纳入会话；不保证模型遵从。
rejected未发送到 SDK，例如 Run 已离开活动状态。
unknown是否纳入无法确认，不换新 messageId 自动重发。
输出示例 202 JSON
{
  "steering": {
    "runId": "run_demo_01",
    "messageId": "msg_demo_02",
    "status": "accepted",
    "code": null
  }
}

边界说明 每 Run 最多 100 条，仅活动且输入就绪的持久 Client 接受新引导；排队、准备文件、保存文件或终态不接受。相同 ID 和文本重试只返回回执，不重复发送；改文本返回 409。默认不打断在途工具，不接收附件、凭据或配置。

接口联动 通过 04 原 SSE 接收 steering.*；没有独立回执 GET。HTTP 超时可用原 messageId 和原文本幂等重试。停止执行用 06。

06 取消任务

地址POST/internal/v1/runs/{runId}/cancel

说明 停止当前任务，或取消已提交的排队任务。

输入 Run JWT，scope 为 run.execute，不消费 jti；路径 runId；无需正文

输入示例 路径及查询参数，不发送正文

POST /internal/v1/runs/run_demo_cancel/cancel

{"runId": "run_demo_cancel"}

输出 200：{"run":Run状态}；取消尚未完成时可返回 504。

输出示例 200 JSON
{
  "run": {"runId": "run_demo_cancel", "status": "cancelled", "lastSequence": 1}
}

边界说明 重复取消不会重复创建取消任务；已有终态直接返回。504 或请求断开不撤销已接收的取消。已产生的文件及外部副作用不会回滚。

接口联动 持续接收 04 终态或调用 03 确认结果；等价于 07 的 option=cancel。

07 中断或取消任务

地址POST/internal/v1/runs/{runId}/control

说明 按 option 中断或取消任务；普通停止按钮使用 06。

输入 Run JWT，scope 为 run.execute；路径 runId；JSON 仅含 option，值为 interrupt 或 cancel；正文最多 1,024 字节

输入示例 JSON 正文

POST /internal/v1/runs/run_demo_control/control

{"option": "cancel"}

输出 200：{"run":Run状态}；状态冲突 409，控制超时 504。

输出示例 200 JSON
{
  "run": {"runId": "run_demo_control", "status": "cancelled", "lastSequence": 1}
}

边界说明 interrupt 消费 jti，每次请求须新授权；cancel 不消费。interrupt 不是暂停/恢复，返回时不保证已有终态。准备、排队及执行中的结果以 Run 状态为准。

接口联动 停止按钮使用 06 或 option=cancel；调用后通过 03/04 确认，不以 HTTP 200 判定执行结束。

08 查询会话任务列表

地址GET/internal/v1/sessions/{businessSessionId}/runs

说明 分页查询同一业务会话下的任务记录。

输入 会话 JWT，scope=session.read，不消费 jti；路径 businessSessionId；limit 默认 50，范围 1–100；cursor 可选，最长 345 字符

输入示例 路径及查询参数，不发送正文

GET /internal/v1/sessions/session_demo_01/runs?limit=20

{"businessSessionId": "session_demo_01", "limit": 20}

输出 200：{"runs":[执行摘要],"nextCursor":字符串或null}。

字段类型与必填说明
runs[].runId / messageIdstring执行标识 / 业务消息标识。
runs[].capabilityRef / statusstring能力及执行状态。
runs[].createdAt / updatedAtintegerUnix 毫秒时间。
nextCursorstring / null原样传入下一页；null 表示没有下一页。
输出示例 200 JSON
{
  "runs": [
    {
      "runId": "run_demo_01",
      "capabilityRef": "conversation",
      "status": "succeeded",
      "createdAt": 1794467502347,
      "updatedAt": 1794467502368,
      "messageId": "msg_demo_01"
    }
  ],
  "nextCursor": null
}

边界说明 按 createdAt、runId 倒序；仅返回 JWT 绑定的 tenant、sub、businessSessionId 范围。没有记录返回空数组。游标无效或跨会话为 400，参数范围/类型错误为 422；不提供业务消息正文。

接口联动 取得 runId 后，另签对应 Run JWT 调 03/04/09。session.read 不能代替 Run 读取授权。

文件

调用方：Java 业务后端。用于补查生成文件和下载本地文件；已上传文件的日常下载由业务文件服务处理。

09 获取文件列表

地址GET/internal/v1/runs/{runId}/artifacts

说明 获取本次任务生成的文件列表及上传状态。

输入 Run JWT，scope 为 run.read 或 run.execute，不消费 jti；路径 runId；无正文，不接受查询参数

输入示例 路径及查询参数，不发送正文

GET /internal/v1/runs/run_demo_01/artifacts

{"runId": "run_demo_01"}

输出 200：{"files":[文件对象]}；未发布文件时为 []。

字段类型与必填说明
artifactIdstring一个文件版本的 Runtime ID；再次发布产生新 ID。
fileIdstring 可选上传成功后返回的平台文件 ID，仅 ready 可用于业务绑定。
name / suffixstring文件名 / 不含点的后缀；文件名不用于定位。
sizeinteger文件字节数。
statusstringpending 待上传；uploading 上传中；ready 成功；failed 失败；unknown 结果不确定。
errorstring 可选失败或不确定时的原因代码。
输出示例 200 JSON
{
  "files": [
    {
      "artifactId": "artifact_0123456789abcdef0123456789abcdef",
      "fileId": "file_demo_01",
      "name": "review.txt",
      "size": 64,
      "suffix": "txt",
      "status": "ready"
    }
  ]
}

边界说明 只列本 Run 登记的成果。携带任何查询参数均返回 400，不支持 ?name= 定位。unknown 不自动重传；Run 成功不代表每个文件都 ready。

接口联动 04 artifact.* 实时更新；10 查单文件，11 读本地快照。ready 后按 fileId 关联业务消息和文件权限。

10 查询文件状态

地址GET/internal/v1/runs/{runId}/artifacts/{artifactId}

说明 按 artifactId 查询一个生成文件的上传状态。

输入 Run JWT，scope 为 run.read 或 run.execute，不消费 jti；路径 runId、artifactId；无正文

输入示例 路径及查询参数，不发送正文

GET /internal/v1/runs/run_demo_01/artifacts/artifact_0123456789abcdef0123456789abcdef

{
  "runId": "run_demo_01",
  "artifactId": "artifact_0123456789abcdef0123456789abcdef"
}

输出 200：{"file":文件对象}，字段同 09。

输出示例 200 JSON
{
  "file": {
    "artifactId": "artifact_0123456789abcdef0123456789abcdef",
    "fileId": "file_demo_01",
    "name": "review.txt",
    "size": 64,
    "suffix": "txt",
    "status": "ready"
  }
}

边界说明 Run 不存在或该 Run 无此文件时为 404；文件名相同不代表同一 artifactId。

接口联动 04 事件或 09 列表取得 artifactId；11 下载该版本。

11 下载文件

地址GET/internal/v1/runs/{runId}/artifacts/{artifactId}/content

说明 下载 Runtime 保存的生成文件；正文为文件字节。

输入 Run JWT，scope 为 run.read 或 run.execute，不消费 jti；路径 runId、artifactId；无正文

输入示例 路径及查询参数，不发送正文

GET /internal/v1/runs/run_demo_01/artifacts/artifact_0123456789abcdef0123456789abcdef/content

{
  "runId": "run_demo_01",
  "artifactId": "artifact_0123456789abcdef0123456789abcdef"
}

输出 200 文件流；Content-Disposition 提供文件名，Content-Type 为推断类型，Cache-Control=no-store。

输出示例 200 响应元信息 JSON；实际正文是文件字节
{
  "statusCode": 200,
  "contentType": "text/plain; charset=utf-8",
  "contentDisposition": "attachment; filename=\"review.txt\"",
  "contentLength": 64
}
文件正文示例 UTF-8 文本文件
文档校对结果：事实、结构和格式已完成检查。

边界说明 文件归属不符、本地快照缺失或不可用为 404。failed/unknown 也可在本地快照仍存在时下载；本地可读不代表远端上传成功。

接口联动 09/10 查状态；本接口由业务端鉴权代理。ready 的远端文件下载由业务文件服务按 fileId 处理。

服务检查

调用方：部署健康探针和运维检查。

12 健康检查

地址GET/health

说明 检查 HTTP 服务是否存活。

输入 无需 JWT；无正文

输入示例 无参数，不发送正文
{}

输出 200：{"ok":true}。

输出示例 200 JSON
{"ok": true}

边界说明 不检查模型、MCP、数据库或文件服务连通性。

接口联动 可用于服务存活探测；不能替代 02 的真实执行验证。

能力管理

调用方：可信管理后端。用于在线配置新能力，日常对话不需要调用；当前本地 Java 和前端代码未接入这组接口。

14 校验能力配置

地址POST/internal/v1/assets/capabilities/validate

说明 检查能力配置的字段、工具依赖和资源引用；只校验，不保存、不执行任务。

输入 管理 JWT，scope 为 assets.manage；JSON 仅含 manifest、prompt；整个请求最多 32,000 字节

字段类型与必填说明

executionobject 可选仅 mode：agent（默认）或 direct。

runtime 字段值或约束

通用约定

JWT 字段

所有 JWT 使用 HS256；iat、exp 是 Unix 秒，exp 须大于 iat。scope 可为单个字符串或字符串数组，不使用空格拼接。业务 Token 只放 credentials.platformBearer，不放 JWT 或 payload。

授权类型必需声明与绑定密钥和限制
Runiss、aud、iat、exp、jti、sub、tenant、runId、capabilityRef、scope。创建时 messageId 必须匹配正文；正文有 businessSessionId 时也必须匹配；后续请求绑定 Run 所属身份、会话和能力。Nacos security.runtimeJwtSecret；iss/aud 默认 string-ai-center-service / ccsdk-runtime，须与当前配置一致。
会话读取iss、aud、iat、exp、jti、sub、tenant、businessSessionId；scope=session.read。与 Run 同密钥及 iss/aud；只读，可在有效期内重复使用。
资产管理iss=string-ai-center-service，aud=ccsdk-runtime-assets；iat、exp、jti、sub；scope 仅 assets.manage。独立 security.assetJwtSecret；有效期最多 300 秒，不得与执行/观测密钥相同。未配置或无效为 401。
观测采集仅 iss、aud、iat、exp、jti、sub、scope 七项；iss=ccsdk-hawkeye，aud=ccsdk-runtime-observability，sub=hawkeye-collector，scope 仅 observation.read。独立 security.observationJwtSecret；有效期最多 300 秒，不接受额外声明。

创建 Run 和 interrupt 消费 jti，重试须新签；其余接口不消费。JWT 过期后须重新授权。密钥和运行预算由 Nacos 提供，不能通过请求正文或旧环境变量覆盖。

错误响应

先看 HTTP 状态和 Content-Type：Run 业务错误通常是 text/plain；资产管理错误为 application/json 的 {"detail":"…"}；框架参数错误为 422 JSON detail 数组。

创建后发生的附件、排队、模型或上游错误，通过 run.failed 的 code/message 和 Run.error 返回；文件上传错误通过 artifact.failed/unknown 返回。

HTTP含义与处理
400正文、字段、游标或配置不合法；修正输入。
401 / 403JWT 校验失败 / 内部接口携带 Origin。
404 / 409资源不存在 / 幂等内容、名称或运行状态冲突。
413 / 422管理请求超过 32,000 字节 / 查询参数类型、范围或长度不合法。
503 / 504执行或观测配置不可用 / 控制超时，继续查 Run 状态。
