业务调用

01 – 07

调用方：Java 业务后端。用于发起任务、接收回答、补充要求、取消任务和查询记录；任务对应一次 Run。

01获取能力列表

GET/internal/v1/capabilities

获取可用能力及是否支持附件，供业务端展示能力列表。

输入无需 JWT；无正文
输出200：{"capabilities":[能力摘要]}。
字段类型与必填说明
capabilityRefstring创建 Run 时使用的能力标识。
name / descriptionstring显示名称和简要说明。
supportsAttachmentsboolean是否接受 input.attachmentRefs。
边界说明

目录不含用户授权结果；返回的能力仍须由业务端筛选并授权。

接口联动

选取 capabilityRef → 02 发起任务。

02发起任务

POST/internal/v1/runs

提交用户消息并启动一次任务，返回任务状态和事件订阅地址。

输入Run JWT，消费 jti；下表为 JSON 正文
字段类型与必填说明
protocolstring 必填固定 agent-run/v1。
runId / messageIdstring 必填分别标识一次执行和触发它的业务消息。
businessSessionIdstring 可选连续会话标识；与 JWT 中的同名字段保持一致。
capabilityRefstring 可选省略或 null 按 conversation 执行；JWT 仍绑定 conversation。空字符串无效。
domainNamestring 必填业务端从已认证学校上下文取得的文件路由域名；只传域名，不含协议、端口或路径。JWT 不绑定此字段。
inputobject 必填可传 {}；text、attachmentRefs、payload 至少一项非空。
input.textstring 可选自然语言需求；默认空串，最多 1,000,000 字符，不含 NUL。
input.attachmentRefsarray 可选最多 64 项；每项仅含 fileId 和 purpose。
fileId / purposestringfileId 必填，为已获授权的平台文件 ID；purpose 为 input（默认）或 reference。
payloadobject 可选默认 {}；JSON 序列化后最多 65,536 UTF-8 字节，嵌套最多 16 层。预制模板传 templateKey。
credentials.platformBearerstring 条件必填当前请求的业务 Token，最多 16,384 字符。能力或所选工具要求时必填；不是 Run JWT。
字段限制

ID 使用英文字母、数字、下划线或连字符，首字符为字母或数字，最长 256 字符。请求和 input 不接受未定义字段。

输出首次创建 202，幂等重试 200：{"run":Run状态,"eventsUrl":"/internal/v1/runs/{runId}/events"}。Run状态字段见 03。
边界说明

传输重试保留 runId 和非凭据正文，重新签发新 jti；不同内容或归属返回 409。重新执行使用新 runId。payload 不得携带凭据、身份或模型/工具/工作目录等执行配置；普通请求使用 {}。HTTP 接收成功不代表执行成功。

接口联动

01 选能力 → 本接口 → 04 SSE；03 补查状态，06 取消，08 查询生成文件。同身份同 businessSessionId 的 Run 串行续接历史，切换能力仍保持会话。

模板和附件

预制模板：document-writing + payload={"templateKey":"szpt-midterm"}。上传模板：在 attachmentRefs 中传已授权 fileId，并在 input.text 说明用途；payload 中的 fileId 不触发下载。附件应在再次需要时重新提交。

输出类型

图表通过 message.delta 返回 Mermaid 正文；图像及文档文件通过 artifact 事件交付。

03查询任务状态

GET/internal/v1/runs/{runId}

查询任务是否排队、执行中、成功、失败或已取消。

输入Run JWT，不消费 jti；路径 runId；无正文
输出200：{"run":Run状态}。创建、查询和取消共用此对象。
字段类型与必填说明
runIdstring执行标识。
statusstringqueued、running、succeeded、failed、cancelled。
lastSequenceinteger已持久化的最大事件序号；无事件时为 0。
errorstring 可选失败原因代码；无错误时省略。
边界说明

不返回回答全文、业务消息或引导回执。404 表示 Run 不存在；不能据此判断鉴权成功。

接口联动

回答及引导回执从 04 补放；续传使用已处理序号，不用 lastSequence 跳过未处理事件。

04订阅任务事件

GET/internal/v1/runs/{runId}/events

接收回答正文、执行进度和文件事件；断线后可补收已保存事件。

输入Run JWT，不消费 jti；路径 runId；查询 afterSequence 为非负整数，默认 0。未传查询参数时可用 Last-Event-ID 请求头
输出200 text/event-stream；每帧含 id、event、data，空行结束。data 是下述 JSON 对象。
字段类型与必填说明
protocolVersionstring固定 agent-events/v1。
runId / eventIdstring执行标识 / 事件标识。
sequence / occurredAtintegerRun 内递增序号 / Unix 毫秒时间。
type / payloadstring / object事件类型和对应数据，见下表。
payload.displayNamestring状态显示文字；空串只隐藏提示，仍须处理该事件。
事件类型关键 payload 字段调用方处理
run.startedstatus=running执行开始，可能仍在准备附件。
phasename；可能带 fileId、receivedBytes、totalBytes、fileCount显示阶段或文件准备进度。
message.deltatextDelta按 sequence 追加正文，同一事件只追加一次。
tool.started / tool.progress / tool.finishedtoolKey、scope、status；可带 toolCallId，结束带 isError按 Run、scope、toolCallId 关联调用，结束时更新状态。
steering.accepted / delivered / applied / rejected / unknownmessageId、status；可带 code关联补充要求，状态含义见 05。
artifact.pending / uploading / ready / failed / unknown文件对象字段，见 08按 artifactId 更新文件卡片；ready 后使用 fileId。
run.completed可带 inputTokens、outputTokens、turnsRun 成功结束；文件是否成功仍看各文件状态。
run.failedcode、message；可带用量Run 失败结束；message 为安全提示。
run.cancelleddisplayNameRun 已停止，保留已收到的内容和文件。
边界说明

仅补放 sequence 大于游标的事件；查询参数优先。心跳是注释帧，不占序号。断开 SSE 不取消 Run；终态后补放完即关闭。已提交文件上传收尾后才发送 Run 终态，但文件仍可能 failed 或 unknown。

接口联动

02 返回 eventsUrl；05 引导沿用原流；断线时用已处理序号重连，必要时配合 03 和 08 补查。

05任务引导

POST/internal/v1/runs/{runId}/steer

向正在执行的任务追加文字要求，继续使用原任务和回答流。

输入Run JWT，不消费 jti；路径 runId；JSON 仅含 messageId 和 input.text
字段类型与必填说明
messageIdstring 必填本次补充要求的唯一标识，不能使用 Run 的原触发 messageId。
input.textstring 必填非空，最多 16,384 字符；不含 NUL；去除前导空白后不能以 / 或 ! 开头。
输出首次接收 202，原请求重试 200：{"steering":{"runId":"…","messageId":"…","status":"accepted","code":null}}。
回执状态含义
accepted已持久接收。
delivered已写入 SDK Client。
appliedSDK 已用消息 UUID 确认纳入会话；不保证模型遵从。
rejected未发送到 SDK，例如 Run 已离开活动状态。
unknown是否纳入无法确认，不换新 messageId 自动重发。
边界说明

每 Run 最多 100 条，仅活动且输入就绪的持久 Client 接受新引导；排队、准备文件、保存文件或终态不接受。相同 ID 和文本重试只返回回执，不重复发送；改文本返回 409。默认不打断在途工具，不接收附件、凭据或配置。

接口联动

通过 04 原 SSE 接收 steering.*；没有独立回执 GET。HTTP 超时可用原 messageId 和原文本幂等重试。停止执行用 06。

06取消任务

POST/internal/v1/runs/{runId}/cancel

停止当前任务，或取消已提交的排队任务。

输入Run JWT，不消费 jti；路径 runId；无需正文
输出200：{"run":Run状态}；取消尚未完成时可返回 504。
边界说明

重复取消不会重复创建取消任务；已有终态直接返回。504 或请求断开不撤销已接收的取消。已产生的文件及外部副作用不会回滚。

接口联动

持续接收 04 终态或调用 03 确认结果；不提供暂停/恢复，继续对话需新建任务。

07查询会话任务列表

GET/internal/v1/sessions/{businessSessionId}/runs

分页查询同一业务会话下的任务记录。

输入会话 JWT，scope=session.read，不消费 jti；路径 businessSessionId；limit 默认 50，范围 1–100；cursor 可选，最长 345 字符
输出200：{"runs":[执行摘要],"nextCursor":字符串或null}。
字段类型与必填说明
runs[].runId / messageIdstring执行标识 / 业务消息标识。
runs[].capabilityRef / statusstring能力及执行状态。
runs[].createdAt / updatedAtintegerUnix 毫秒时间。
nextCursorstring / null原样传入下一页；null 表示没有下一页。
边界说明

按 createdAt、runId 倒序；仅返回 JWT 绑定的 tenant、sub、businessSessionId 范围。没有记录返回空数组。游标无效或跨会话为 400，参数范围/类型错误为 422；不提供业务消息正文。

接口联动

取得 runId 后，另签对应 Run JWT 调 03/04/08。session.read 不能代替 Run 读取授权。

文件

08 – 10

调用方：Java 业务后端。用于补查生成文件和下载本地文件；已上传文件的日常下载由业务文件服务处理。

08获取文件列表

GET/internal/v1/runs/{runId}/artifacts

获取本次任务生成的文件列表及上传状态。

输入Run JWT，不消费 jti；路径 runId；无正文，不接受查询参数
输出200：{"files":[文件对象]}；未发布文件时为 []。
字段类型与必填说明
artifactIdstring一个文件版本的 Runtime ID；再次发布产生新 ID。
fileIdstring 可选上传成功后返回的平台文件 ID，仅 ready 可用于业务绑定。
name / suffixstring文件名 / 不含点的后缀；文件名不用于定位。
sizeinteger文件字节数。
statusstringpending 待上传；uploading 上传中；ready 成功；failed 失败；unknown 结果不确定。
errorstring 可选失败或不确定时的原因代码。
边界说明

只列本 Run 登记的成果。携带任何查询参数均返回 400，不支持 ?name= 定位。unknown 不自动重传；Run 成功不代表每个文件都 ready。

接口联动

04 artifact.* 实时更新；09 查单文件，10 读本地快照。ready 后按 fileId 关联业务消息和文件权限。

09查询文件状态

GET/internal/v1/runs/{runId}/artifacts/{artifactId}

按 artifactId 查询一个生成文件的上传状态。

输入Run JWT，不消费 jti；路径 runId、artifactId；无正文
输出200：{"file":文件对象}，字段同 08。
边界说明

Run 不存在或该 Run 无此文件时为 404；文件名相同不代表同一 artifactId。

接口联动

04 事件或 08 列表取得 artifactId；10 下载该版本。

10下载文件

GET/internal/v1/runs/{runId}/artifacts/{artifactId}/content

下载 Runtime 保存的生成文件；正文为文件字节。

输入Run JWT，不消费 jti；路径 runId、artifactId；无正文
输出200 文件流；Content-Disposition 提供文件名，Content-Type 为推断类型，Cache-Control=no-store。
边界说明

文件归属不符、本地快照缺失或不可用为 404。failed/unknown 也可在本地快照仍存在时下载；本地可读不代表远端上传成功。

接口联动

08/09 查状态；本接口由业务端鉴权代理。ready 的远端文件下载由业务文件服务按 fileId 处理。

11健康检查

GET/health

检查 HTTP 服务是否存活。

输入无需 JWT；无正文
输出200：{"ok":true}。
边界说明

不检查模型、MCP、数据库或文件服务连通性。

接口联动

可用于服务存活探测；不能替代 02 的真实执行验证。

观测

12 – 15

调用方：CCSDKHawkeye 等观测平台。用于采集运行记录、资源状态和监控指标。

12获取实例信息

GET/internal/observability/v1/info

获取被监控实例的标识、版本和可采集范围。

输入观测 JWT，scope 为 observation.read；无正文
输出200：version、epoch、instanceId、python、sdk、clock、signals。
边界说明

version 为 1；signals 表示 runtime、actor、pool、worker、details 可采集，java 和 modelHttp 未埋点。观测关闭为 404；鉴权未配置为 503，无效 JWT 为 401。

接口联动

先登记 instanceId/epoch，再用 13 拉记录；15 响应头可核对实例。

13获取观测记录

GET/internal/observability/v1/records

按游标分页获取观测记录，用于追踪任务执行过程。

输入观测 JWT，scope 为 observation.read；cursor 为非负整数，默认 0；limit 默认 200，范围 1–500
输出200：以下字段。
字段类型与必填说明
epochstring观测库代次；变化时重新登记并开始新游标。
records[]objectsequence、kind、runId、traceId、timestamp、data；data 随 kind 变化。
nextCursorinteger下一次请求使用的游标。
oldestCursor / latestCursorinteger / null保留范围下界 / 最新水位；空库的 oldestCursor 可为 null。
gap / hasMoreboolean游标已落在保留范围外 / 还有后续记录。
边界说明

读取不消费记录，各采集方各自保存游标。gap=true 代表历史缺口；记录全部过期仍可能有水位。时间戳为 Unix 毫秒，本接口不是业务 SSE。

接口联动

12 确认 epoch；有 hasMore 继续拉取。即时状态可配合 14，聚合指标见 15。

14获取运行状态

GET/internal/observability/v1/snapshot

获取当前会话、Worker 池和进程内存状态，用于监控看板。

输入观测 JWT，scope 为 observation.read；无正文
输出200：timestamp、actors[]、pool、processes[]、dropped。
字段类型与必填说明
timestamp / droppedintegerUnix 毫秒时间 / 当前观测实例累计丢弃记录数。
pendingRunsinteger已入队而尚未分派的 Run 数，包括等待会话、准备附件和等待资源的 Run。
actors[]object会话执行器快照，如 sessionKey、state、activeRunId、pendingRuns、workerPid、lastErrorCode。
poolobject / nullWorker 池快照，如 ready、starting、live、businessStarting、hits、misses、memory_paused；未启动为 null。
processes[]object进程树内存采样；无 Worker 时为空数组。
边界说明

是即时内部快照，不是持久历史，也不能据此推断浏览器首字时间。actors/pool 为诊断字段，业务接入不依赖其内部结构。

接口联动

13 查询执行过程；15 读取数值指标；业务状态使用 03/07。

15获取监控指标

GET/internal/observability/v1/metrics

获取 Prometheus 格式的数值指标，供监控系统采集。

输入观测 JWT，scope 为 observation.read；无正文
输出200 text/plain; version=0.0.4；响应头 X-CCSDK-Instance-ID；正文为指标名称和数值。
边界说明

ccsdk_run_queue_depth 是未分派的 Run 数，ccsdk_actor_queue_depth 是 Actor 内部待执行数；可用指标随启用组件和采集事件变化。只覆盖 Python 执行侧。

接口联动

X-CCSDK-Instance-ID 与 12 登记值核对；13 提供明细事件，14 提供即时快照。

通用约定

JWT、错误

JWT 字段

所有 JWT 使用 HS256；iat、exp 是 Unix 秒，exp 须大于 iat。Run JWT 不要求或校验 scope；会话和观测 JWT 的 scope 可为单个字符串或字符串数组。业务 Token 只放 credentials.platformBearer，不放 JWT 或 payload。

授权类型必需声明与绑定密钥和限制
Runiss、aud、iat、exp、jti、sub、tenant、runId、capabilityRef。创建时 messageId 必须匹配正文；正文有 businessSessionId 时也必须匹配；后续请求绑定 Run 所属身份、会话和能力。MySQL settings/security 的 secrets.runtimeJwtSecret；iss/aud 须分别匹配 value.runtimeJwtIssuer / value.runtimeJwtAudience。
会话读取iss、aud、iat、exp、jti、sub、tenant、businessSessionId；scope=session.read。与 Run 同密钥及 iss/aud；只读，可在有效期内重复使用。
观测采集仅 iss、aud、iat、exp、jti、sub、scope 七项；iss=ccsdk-hawkeye，aud=ccsdk-runtime-observability，sub=hawkeye-collector，scope 仅 observation.read。MySQL settings/security 的 secrets.observationJwtSecret 独立密钥；有效期最多 300 秒，不接受额外声明。

创建 Run 消费 jti，重试须新签；其余接口不消费。JWT 过期后须重新授权。密钥与公共运行预算分别来自 MySQL settings/security、settings/runtime，单 Run 预算见 ccsdk_capability.config.runtime。启动 YAML 仅保存配置库引导与宿主机参数；不读取 Nacos、环境变量或 .local 覆盖，普通 Run 正文不能修改执行配置。详见配置参考。

错误响应

先看 HTTP 状态和 Content-Type：Run 业务错误通常是 text/plain；框架参数错误为 422 JSON detail 数组。

创建后发生的附件、排队、模型或上游错误，通过 run.failed 的 code/message 和 Run.error 返回；文件上传错误通过 artifact.failed/unknown 返回。

HTTP含义与处理
400正文、字段、游标或配置不合法；修正输入。
401 / 403JWT 校验失败 / 内部接口携带 Origin。
404 / 409资源不存在 / 幂等内容或引导状态冲突。
422查询参数类型、范围或长度不合法。
503 / 504执行或观测配置不可用 / 取消超时，继续查 Run 状态。
