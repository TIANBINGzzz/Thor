# ADR-NNN: 标题

| 字段 | 内容 |
| --- | --- |
| 决策日期 | YYYY-MM-DD；旧决策沿用原日期 |
| 决策状态 | 提议 |
| 实现状态 | 未开始 |
| 最近核对 | YYYY-MM-DD |
| 替代的旧 ADR | 无；有则链接并注明替代范围 |
| 被哪份 ADR 替代 | 无；有则链接并注明替代范围 |

## 背景

一两句话说明问题、适用范围与关键约束。

## 决策

- 采用什么及必要理由；关键替代方案只写未选原因，接口字段链接契约。

## 后果与验证

- 收益、成本和风险；已落地代码、实际验证日期/结果及未验收范围。未执行的检查不得写通过。
