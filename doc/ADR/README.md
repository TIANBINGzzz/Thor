## 编写约定

- 新增技术选型、安全边界或明确放弃方案时使用[模板](template.md)，普通修复、代码说明和临时想法不新建 ADR。
- 正文优先 20-30 行，最多 50 行；区分决策状态与实现状态。已采纳不等于已实现，本地验证不等于生产验收。
- 决策状态使用提议、已采纳、已替代、已废弃或已拒绝；实现状态注明已落地范围、验证日期和剩余差距。
- 修改方案须逐条检查[工程要求](../specs/engineering-requirements.md)。替代关系在新旧记录中互相标明，已删除正文的关系保留在下表。
- 过期或重复正文可以删除，保留编号、去向和删除日期，历史从 Git 恢复；不要另建一套归档副本。
