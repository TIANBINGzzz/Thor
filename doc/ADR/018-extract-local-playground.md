## 背景
Java 接入只需要执行服务；同仓测试 UI、会话存储和本地身份文件分支会混淆业务授权边界。

## 决策
- 本仓库只保留 Runtime、SDK、执行资产和运行数据；业务 UI、消息/会话及文件 ACL 归 Java/前端。
- 输入统一使用授权文件引用，不增加测试身份直读本地文件的分支；接口测试遵守同一 Runtime 契约。
- 原 Next UI、上传和测试控制面曾迁入 ScribePlayground，后按用户要求删除，该项目的历史验证不作为当前接入说明。

## 后果与验证
- 执行部署独立，业务接口保持明确；端到端验证需要外部调用方，不能用模拟控制面证明真实 Java 授权。
- 2026-09-09 曾通过 Runtime/Playground 测试、Next 构建及 SDK 附件/SSE/取消联调；该证据仅适用于拆分当时的版本。
- 2026-09-21 移除独立测试项目，历史从 Git 恢复；生产业务链路仍须独立验收。
