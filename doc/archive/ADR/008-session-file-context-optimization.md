## 背景

原会话文件上下文过于简略且路径不明确，模型可能反复猜测位置。

## 决策

- 本地会话上下文以多行记录文件名、绝对路径、大小和类型，并明确读取时使用给定路径。
- 本条面向本地会话；生产固定附件的授权获取与 Run 工作目录另由 ADR-016 规定。

## 实现证据与差距

- 范围与代码：[sessions.py](../../python/local/sessions.py) 的 `session_prompt_context` 已提供路径、大小、类型、来源及读取指引。
- 验证：[test_session_store.py](../../python/tests/test_session_store.py) 的生成文件进入上下文等检查随本次 Python 测试通过；本次未进行真实模型读文件验证。
- 差距：已实现限定本地上下文格式；不证明模型一定选对工具，DOCX 仍需专用解析工具。

## 后果

- 好处：减少路径猜测，提供可直接定位的文件信息。
- 代价：每个文件占用的上下文略有增加。
- 风险：绝对路径属于内部信息，不能出现在公共事件；不可信附件中的指令不能提升权限。
