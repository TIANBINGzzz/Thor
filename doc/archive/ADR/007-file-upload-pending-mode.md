## 背景

选择文件即上传使用户无法在发送前检查或取消附件。

## 决策

- 选择或粘贴文件后先显示待上传列表，允许逐项移除；发送时统一上传，完成后清空列表。
- 后续的上传失败阻止发送及文件一致性约定见 ADR-010，本条只规定待上传交互。

## 实现证据与差距

- 范围与代码：[ChatWorkspace.tsx](../../web/app/components/ChatWorkspace.tsx) 的 `pendingFiles`、粘贴处理、移除按钮和 `uploadPendingAndSend`。
- 验证：本次源码核对确认选择/粘贴只入队、发送前上传；未执行浏览器上传交互回归。
- 差距：大文件等待时间、重复操作及上传失败的真实用户体验仍需场景验证；不代表生产附件链路验收。

## 后果

- 好处：用户可在发送前检查并取消附件，支持批量选择。
- 代价：维护待上传队列和异步发送状态。
- 风险：大文件上传占用发送前等待时间；必须避免重复发送。
