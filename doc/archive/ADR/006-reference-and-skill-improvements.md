## 背景

原引用选择缺少视觉反馈，发送后输入残留，并缺少 Skill 引用和粘贴文件入口。

## 决策

- 增加 `@skill:` 数据源，扫描 `.claude/skills/` 并短期缓存，保持与项目 Skill 文件同步。
- 引用以分类彩色标签显示；提交后清空输入与引用面板，支持粘贴文件进入上传流程。

## 实现证据与差距

- 范围与代码：[references.py](../../python/local/references.py) 的 Skill 数据源；当前生效的标签、输入清空和粘贴处理在 [ChatWorkspace.tsx](../../web/app/components/ChatWorkspace.tsx)。
- 验证：[test_references.py](../../python/tests/test_references.py) 的数据源检查随本次 Python 测试通过；前端行为本次仅源码核对，未重跑浏览器交互。
- 差距：不以旧 `ReferenceChips` 组件存在证明当前页面已使用；大量 Skill 的加载性能未验收。

## 后果

- 好处：选中对象可见，输入行为一致，文件入口更便捷。
- 代价：维护引用标签、输入状态、缓存与粘贴事件。
- 风险：缓存会短暂滞后于 Skill 文件更新；任意 Skill 引用不应成为生产授权入口。
