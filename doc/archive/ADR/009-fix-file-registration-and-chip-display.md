## 背景

曾出现文件已落盘但会话文件清单未注册，以及引用标签与输入区域混在一起的问题。

## 决策

- 引用标签独立展示，与输入区有明确视觉分隔，空状态不保留无意义占位。
- 上传时加载会话后更新文件记录并持久化，使文件清单与模型上下文一致；保持内存会话与持久状态同步。

## 实现证据与差距

- 范围与代码：[sessions.py](../../python/local/sessions.py) 的 `save_uploads` 加载会话、记录文件并 `_persist_session`；当前标签在 [ChatWorkspace.tsx](../../web/app/components/ChatWorkspace.tsx)。
- 验证：[test_session_store.py](../../python/tests/test_session_store.py) 的上传记录、文件名和会话共享状态检查随本次 Python 测试通过；标签布局仅核对源码。
- 差距：本次未重跑浏览器视觉/交互检查及多进程并发上传；不以历史缓存问题已修复推导生产并发安全。

## 后果

- 好处：已上传文件可在会话和上下文中查到，引用标签更易辨认。
- 代价：上传需要同步更新会话记录与磁盘状态。
- 风险：文件落盘和会话持久化不是跨资源事务，异常及并发路径仍需专门验证。
