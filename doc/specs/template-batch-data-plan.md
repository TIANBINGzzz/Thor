# 模板取证与自主撰写

当前采用[ADR-027](../ADR/027-agent-led-document-writing.md)：共同规则和可信上下文交给Agent，程序不编排逐段草稿。

| 资产/模块 | 职责 |
| --- | --- |
| template.json、writing-guide.md | 登记所选DOCX、来源与指南；维护主题、指标引用、特殊口径和必查项 |
| template_assets.py | 校验可信选择、冻结实际文件及指南版本、复制参考DOCX到工作目录 |
| 主题指标YAML及data工具 | 维护指标/SQL，解析授权范围、执行只读查询、保存本Run结果引用 |
| 通用DOCX、文件和代码工具 | Agent读取结构，自主选择编辑或生成方法 |
| Artifact工具 | 校验文件范围并发布；不代替内容与版式验收 |
| document-map.json、report-data-plan.json | 可选维护参考，不在运行时加载、展开或执行 |

预制模板、上传模板、无模板共用document-writing能力和writing-docx Workflow。预制模板额外提供所选指南及参考副本，上传模板仍通过授权附件读取；外部传值不变。

Agent根据正文主题规划取证，按需检索指标、执行查询、读取完整结果及材料后撰写。缺定义不编造SQL；证据不足写有限结论和缺口，完全无证据沿原主题写分析框架、数据需求及后续动作，不确定内容标黄。旧逐页核对文件及验证过的主题SQL继续保留。

没有强制dataset_keys、target、evidence_state草稿字段或报告专用发布门禁。证据和来源须能追溯，但具体工作记录由Agent选择。目录重建、逐页渲染、样式和事实检查仍为交稿要求；没做的检查必须如实说明，发布成功不代表内容审核通过。

模板源DOCX或指南变化会形成新的执行版本；副本不覆盖已有修改。地图缺失、损坏或过期不阻止启动。完整工具权限和bypassPermissions不是生产沙箱，完整报告、复杂目录及真实Java链路尚未端到端验收。

| 要求 | 状态 | 依据与差距 |
| --- | --- | --- |
| REQ-001 | 不适用 | 未改Token注入，既有Java验收差距保留 |
| REQ-002 | 部分满足 | 同能力、可信模板/来源选择，外部字段不变；真实Java授权未验收 |
