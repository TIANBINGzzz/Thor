# 数据长报告撰写

交付指定报告的 DOCX 和 PDF，按预制底稿排版。直接完成证据、正文、文档三个成果，正文必须进入成稿并完成发布。

**证据。** 先读本轮已提供的数据库上下文，确定项目及各自实际阶段，再并行获取需要的汇总。固定指标覆盖的口径直接用查询结果。对固定指标缺少的必需统计，调用授权只读聚合 SQL，限定同一学校下的所选项目和实际阶段。不要逐项试查或读取原始反馈全文。遇到非重试错误按返回原因修正一轮，仍取不到就带缺项继续。年度资金、项目全周期预算各自列示，写清预算、到位、执行对应的分子、分母及非空数。各项目反馈先校验全层级合计，再按需要分层，分层小计不可替代全层级合计。覆盖率分子是期内已审核反馈涉及的去重任务数，分母使用对应层级任务数。区分附件字段存在与实际核验。保留现状取数时点、零、未填、无记录、未定义的分别说明。搜索只发送公开检索词，一轮查对应周期的官方原文，必要时补搜一次。原文未核实则披露，台账缺项按实际状态记录。

**正文。** 用本轮工作目录中的同一份核实数据生成正文、表格和图片。先撰写完整正文，按题目核对字数、章节、数值、五类表与三幅图，再进入文档编辑。关系图展示各项目的实际一级任务。统计图按核实数值确定性绘制并标注单位、日期和口径，缺失值不画为零。只有额外示意图可以调用生图，输入仅用公开通用描述，并标明性质。

**文档。** 把底稿另存为唯一工作稿。至多一次只读 outline 检查底稿结构。保留独立封面、真实 TOC、节和页码。先用脚本从正文、表图数据生成一份完整 OfficeCLI JSON 操作数组，再用一次 batch --input 集中填封面、替换正文样例、写标题、正文、真实表格和图片；模板样式优先。给长表设置重复首行、禁止切断行；图与图注紧邻。代码只用于整理内容、画图和生成操作 JSON。把 outline 放在 batch 末尾，如果确有一个命令不明确，查一次该命令帮助。不要创建探测稿或逐段、逐表重复查看。

**核验及交付。** close 后调用文档渲染。优先使用渲染响应中的目录状态、分页文字和页面图。可一次生成每组四页的缩略拼图，分组并行看过全部页面，只放大疑点。确认完整的章节、真实目录、图表、正文编号和没有空白或不可读页面后立即发布同次渲染返回的 DOCX 与 PDF。确有影响验收的问题时集中修一次并渲染一次，完成后提交可用的测试稿，简述仍有的缺项或版式问题。不要为字体微调、行尾标点或没有新证据的问题进入第三次渲染。
